# deskbird — Senior Growth Analyst Take-Home Case

Submission for the Senior Growth Analyst take-home case study.

## Contents

- **`deskbird_growth_analysis.ipynb`** — full analysis notebook: data quality checks, the 5 growth metrics, exploratory insights, data model, and recommendations, with all reasoning shown.
- **`deskbird_growth_analysis_condensed.ipynb`** — a leaner companion covering the same ground more concisely.
- **`deskbird_data_model.html`** — interactive dbt-style data model reference (lineage diagram, model reference table, design notes). [View live](https://mohamadsaad-1993.github.io/DeskBird-Case/deskbird_data_model.html).
- **`crm_pipeline.csv`, `paid_ads.csv`, `product_usage_events.csv`** — the 3 raw datasets provided for the case.

The accompanying slide deck (data model, KPIs, insights, and recommendations) is the primary deliverable and was shared separately.
